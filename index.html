Frequently Asked Questions

What is the Model Context Protocol (MCP)?

MCP is an open standard developed by Anthropic that allows AI agents like Claude Desktop, Cursor, and Antigravity to securely connect to local tools and data sources on your computer.

How does ContextCut actually save money?

Frontier LLMs charge per input token. When your agent scans a 10,000-line codebase to understand its architecture, it ingests loops, regex, and internal logic that isn't needed. ContextCut stubs out internal function bodies while preserving signatures, cutting token bills by 50% to 80% on every prompt.

How does the built-in cost-benefit & ROI reporting work?

Every time ContextCut prunes a file or directory, it automatically logs an anonymous, lightweight record to your private local ledger at ~/.contextcut/history.jsonl. You can ask Claude or Antigravity "What are my ContextCut savings this week?" or run node build/index.js report --interval=weekly in your terminal to see exact token counts, hours of latency saved, and estimated dollars saved based on current frontier model pricing.

What is Agent Autopilot Mode and how do I enable it?

Autopilot Mode instructs your AI coding agent (in Cursor, Claude Desktop, or Antigravity) to automatically route files through ContextCut before analyzing architecture, classes, or interfaces. You can enable it with one command: npx contextcut-mcp init, which safely writes the rule to your project's .cursorrules and CLAUDE.md files.

Does my code ever get uploaded to your servers?

Never. ContextCut runs 100% locally on your machine. AST analysis and code transformation occur entirely in memory within your local process.
